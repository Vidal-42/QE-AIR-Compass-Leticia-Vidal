# ATIVIDADES COM GIT E GITHUB - AI/R CompassUOL

## Atividade Individual

Com base no conhecimento adquirido em relação a versionamento GIT, foi criado um repositório para ser utilizado daqui para frente, e neste repositório subi todos os arquivos relevantes das Sprints anteriores, como arquivos de planejamento de testes, mapas mentais, collections Postman entre outros.
O repositório foi versionado com branches, e os arquivos do PB estão organizados dentro de uma pasta chamada "Documentos". Também foi criado um README dando uma breve introdução ao repositório.

## Atividade em grupo

A partir dos conhecimentos adquiridos com Git, a SQUAD 3, da qual faço parte, se reuniu para criar um repositório que deve ser compartilhado entre todos os membros. Foi tabalhado o versionamento de arquivos em diferentes branches e foram realizados merges.
Nossa Squad criou uma história em um documento .txt, e cada membro  colaborou com uma parte da história. Ao fim, todos realizaram o merge do arquivo da história para a branch main. Durante a evolução, foram realizadas merges da main para as branches de cada integrante, trabalhando com boas práticas durante o uso do Git.
